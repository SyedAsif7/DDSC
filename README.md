## 🚀 Overview

This is the official platform for the **DCode Student Developer Club**, showcasing our journey, achievements, and the vibrant technical community we're building. Designed with a cinematic, technical aesthetic, the site serves as a central hub for student developers to explore events, meet the leadership, and join our growing ecosystem.

---

## ✨ Key Features

- **Cinematic Experience:** High-end glassmorphism UI optimized for video backgrounds with 40px backdrop blurs and technical glow effects.
- **Chapter-Based Team Management:** A modular system managing both legacy (Chapter 1) and upcoming (Chapter 2) team data with a sleek toggle interface.
- **Dynamic Content:** Real-time data management for achievements, upcoming events, and project showcases.
- **Responsive Architecture:** Mobile-first, fluid layouts ensuring a premium experience across all device sizes.
- **Technical Aesthetic:** Custom animations (`shimmer`, `scan`, `float`), technical badges, and status-driven UI components.
- **Interactive Sections:** Dedicated areas for Club History, Gallery, Partners, and Achievement details.

---

## 🛠️ Tech Stack

### Frontend Core
- **React 18**: Component-based architecture for a dynamic UI.
- **TypeScript**: Type-safe development for enhanced reliability and maintenance.
- **Vite**: Ultra-fast build tool and development server.

### UI & Styling
- **Tailwind CSS**: Utility-first styling with custom animation keyframes.
- **Shadcn UI**: Accessible, high-quality primitive components built on Radix UI.
- **Lucide React**: Clean, consistent technical iconography.
- **Framer Motion**: (Planned) Advanced interaction and entrance animations.

## 🚀 Getting Started

### Prerequisites

- **Node.js**: v18.x or higher
- **npm**: v9.x or higher

### Installation & Development

1. **Clone the Repository**
   ```bash
   git clone https://github.com/SyedAsif7/DDSC-main.git
   cd DDSC-main
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Launch Development Server**
   ```bash
   npm run dev
   ```
   The application will be accessible at `http://localhost:5173`.

### Build for Production

```bash
npm run build
```
The optimized production build will be generated in the `dist/` directory.

## 📁 Project Structure

```
src/
├── components/          # React Components
│   ├── layout/          # Global layout (Navbar, Footer, Video Background)
│   ├── sections/        # Main landing page sections (Team, About, Gallery, etc.)
│   └── ui/              # Base UI components (shadcn primitives)
├── data/                # Static data (Team configurations, Events, Achievements)
├── hooks/               # Custom React hooks (Mobile detection, Toasting, etc.)
├── pages/               # Main page routes (Index, Details, NotFound)
├── lib/                 # Utility functions and core configuration
└── assets/              # Static assets and global styles
```
